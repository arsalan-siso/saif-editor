## 📖 عن المشروع

**محرر سيف المتكامل** هو بيئة تطوير متكاملة (IDE) مصممة خصيصاً للغة البرمجة العربية **"سيف"**. 

هذا المشروع هو نتيجة جهد لتوفير تجربة برمجة سلسة للمطورين العرب، حيث يوفر:
- دعم كامل للغة العربية في الواجهة والكتابة
- تمييز النصوص (Syntax Highlighting) للكلمات المفتاحية والمكتبات
- ترجمة فورية للكود وتشغيله بنقرة واحدة
- بيئة تطوير متكاملة بكل ما تحتاجه من أدوات

> 🎯 **الهدف**: تسهيل تجربة البرمجة بالعربية وتوفير أدوات احترافية للمطورين العرب دون الحاجة لتعلم الإنجليزية.

## 📦 التثبيت التفصيلي

### الطريقة 1: التحميل المباشر (موصى به)

# 1. تحميل المشروع
git clone https://github.com/arsalan-siso/saif-editor.git

./run.sh

```bash
# 1. نسخ المجلد

# 3. تشغيل من أي مكان
saif-ide
```

```

### 3. الترجمة والتشغيل

| الطريقة | الشرح |
|---------|-------|
| **زر الترجمة** | اضغط على زر `ترجمة` في شريط الأدوات |
| **زر التشغيل** | اضغط على زر `تشغيل` في شريط الأدوات |
| **اختصار F8** | ترجمة الكود الحالي |
| **اختصار F9** | تشغيل البرنامج بعد الترجمة |
| **Ctrl+R** | ترجمة وتشغيل مباشر (خطوة واحدة) |

### 4. من سطر الأوامر

```bash
# ترجمة فقط
./bin/حداد2 مشروعي.سيف

# ترجمة وتشغيل
./bin/حداد2 مشروعي.سيف -r

# تحديد اسم ملف الإخراج
./bin/حداد2 مشروعي.سيف -o برنامجي

# عرض المساعدة
./bin/حداد2 -h
```

## 🎯 أمثلة عملية

### مثال 1: برنامج "مرحباً بالعالم"

```c
#ادرج "كرتونة.ع"

عدد رئيسي() {
    اكتب_سطر("مرحباً من سيف!");
    ارجع نجاح;
}
```

**النتيجة**: عند التشغيل ستظهر `مرحباً من سيف!` في الطرفية.

**شرح الكود:**
- `#ادرج "كرتونة.ع"` : تضمين المكتبة الأساسية
- `عدد رئيسي()` : تعريف الدالة الرئيسية
- `اكتب_سطر()` : طباعة نص
- `ارجع نجاح` : إنهاء البرنامج بنجاح

### مثال 2: برنامج رسومي (نافذة)

```c
#ادرج "بصمة.ع"
#ادرج "كرتونة.ع"

عدد رئيسي() {
    ابدأ_الرسوم();
    
    نافذة *نو = افتتح_نافذة("نافذتي", 800, 600);
    راسم *رس = افتتح_راسم(نو);
    
    استعمل_لون(رس, 0, 255, 0);
    امسح_اللوحة(رس);
    اظهر_اللوحة(رس);
    
    انتظر(3000);
    
    اغلق_راسم(رس);
    اغلق_نافذة(نو);
    اختم_الرسوم();
    
    ارجع نجاح;
}
```

**النتيجة**: نافذة خضراء تظهر لمدة 3 ثوانٍ ثم تغلق.

**شرح الكود:**
- `#ادرج "بصمة.ع"` : تضمين مكتبة الرسوميات
- `ابدأ_الرسوم()` : تهيئة الرسوميات
- `افتتح_نافذة()` : إنشاء نافذة
- `استعمل_لون()` : تحديد لون الرسم
- `امسح_اللوحة()` : مسح الشاشة باللون المحدد
- `اظهر_اللوحة()` : عرض التغييرات

### مثال 3: آلة حاسبة بسيطة

```c
#ادرج "كرتونة.ع"

عدد رئيسي() {
    عدد أ, ب;
    محرف ع;
    
    اكتب("العملية (+ - * /): ");
    اقرأ(" %c", &ع);
    اكتب("العدد الأول: ");
    اقرأ("%d", &أ);
    اكتب("العدد الثاني: ");
    اقرأ("%d", &ب);
    
    تفرع (ع) {
        حالة '+': اكتب("%d\n", أ + ب); توقف;
        حالة '-': اكتب("%d\n", أ - ب); توقف;
        حالة '*': اكتب("%d\n", أ * ب); توقف;
        حالة '/': 
            اذا (ب != 0) اكتب("%d\n", أ / ب);
            والا اكتب_سطر("خطأ: القسمة على صفر!");
            توقف;
        افتراضي: اكتب_سطر("عملية غير معروفة!");
    }
    
    ارجع نجاح;
}
```

**النتيجة**: برنامج تفاعلي يقوم بالعمليات الحسابية الأساسية.

## 🐛 استكشاف الأخطاء وإصلاحها

| المشكلة | السبب | الحل |
