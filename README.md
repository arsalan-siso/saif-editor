## 📖 عن المشروع

**محرر سيف المتكامل** هو بيئة تطوير متكاملة (IDE) مصممة خصيصاً للغة البرمجة العربية **"سيف"**. يهدف هذا المشروع إلى توفير تجربة برمجة سلسة للمطورين العرب، مع دعم كامل للغة العربية، تمييز النصوص، الترجمة، والتشغيل الفوري.

> 🎯 **الهدف**: تسهيل تجربة البرمجة بالعربية وتوفير أدوات احترافية للمطورين

---

## ✨ مميزات المحرر

| الميزة | الوصف |
|--------|-------|
| 🌐 **دعم اللغة العربية** | واجهة عربية بالكامل مع دعم الكتابة من اليمين لليسار (RTL) |
| 🎨 **تمييز النصوص** | تمييز تلقائي للكلمات المفتاحية والمكتبات والدوال |
| 📦 **مكتبات مدمجة** | جميع مكتبات سيف مدمجة (كرتونة.ع، بصمة.ع، خط.ع، صوت.ع) |
| 🖥️ **SDL2 مرفقة** | لا حاجة لتثبيت SDL2 - كل شيء مرفق مع المحرر |
| ⚡ **ترجمة وتشغيل فوري** | زر واحد للترجمة والتشغيل المباشر |
| 📁 **إدارة المشاريع** | مجلد مخصص للمشاريع مع ملفات نموذجية |
| 🔍 **بحث واستبدال** | أدوات بحث واستبدال متقدمة |
| 📝 **إكمال الكود** | إكمال تلقائي للكلمات المفتاحية |

## 🚀 التشغيل السريع

```bash
# 1. تحميل المشروع
git clone https://github.com/arsalan-siso/saif-editor.git
cd saif-editor

# 2. تثبيت المتطلبات
sudo apt install geany

# 3. تشغيل المحرر
# 1. فك الضغط
tar -xzf saif-editor-core.tar.gz
cd saif-editor

# 2. تشغيل المحرر
./run.sh
